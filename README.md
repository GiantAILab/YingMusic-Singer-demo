## 📝 About the Paper

This is the demo page for the paper: [**"YingMusic-Singer: Zero-shot Singing Voice Synthesis and Editing with Annotation-free Melody Guidance"**](https://arxiv.org/pdf/2512.04779).

## 🎧 Audio Samples

The demo page showcases side-by-side comparisons of:
- **Ground Truth**: The original recording.
- **Model Outputs**: Synthesized audio from various neural models.
- **Lyrics**: Interactive lyrics display with highlighting.

## 🛠️ Local Development

If you want to run this demo locally or customize it:

### Prerequisites
- Node.js 20+
- npm

### Installation
```bash
npm install
```

### Run Locally
```bash
npm run dev
```

### Build for Deployment
```bash
npm run build
```

## 📂 Project Structure

- `src/App.tsx`: Main entry point with paper information.
- `public/data/default/data.json`: The audio sample metadata.
- `public/audio/`: Folder containing the audio files.
